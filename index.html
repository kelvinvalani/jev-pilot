Jev Fast

Manifest V3 Chrome extension. Jev picks the next click or keystroke from the live DOM; the page executes it. This page is a UI preview — load the folder as an unpacked extension to control a real tab.

  1. Open chrome://extensions and enable Developer mode.
  2. Load unpacked and select this project folder.
  3. Choose BeatAPI or TypeSafe, paste that provider’s key, open a site (or the flight playground), and start a goal.
