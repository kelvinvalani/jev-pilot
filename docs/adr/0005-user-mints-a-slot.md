# The user mints a slot from the field label

Slots are not a closed catalog, and a field that matches nothing does not silently become a slot. The user is asked. They attach the field to an existing slot, or they create a slot and type its answer. The field's label is the new slot's name and its first alias. They can rename the slot in the profile. A closed catalog was rejected because a form will eventually ask for a fact we did not ship. Silent naming was rejected because two wordings of one fact would become two slots.
