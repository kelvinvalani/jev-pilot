# Fill the page the user already has open

Jev Fast was a goal-driven automater: the user typed a task, and the extension clicked, typed, and moved through the page. The product is a form filler. A fill writes profile answers into fields on the page already open, and the user clicks Continue or Submit themselves. Filling and then submitting was rejected because sending a form is a different act from writing the answers. Keeping the automater and treating fill as one step inside a task was rejected because the typed goal is no longer the product.
