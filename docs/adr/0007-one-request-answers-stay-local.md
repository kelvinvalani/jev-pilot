# One request per fill, and answers stay local

A fill asks Jev once. The request carries the empty fields of the target form, the slot names, the situation names, and the aliases. It does not carry answer strings. Each field is one choice, because the questions in a request are answered independently and a second question cannot use the first answer. The options are every existing pair of a slot and a situation, every pair of a slot and its default, a new-situation option for each slot, and none. The default option means the heading is the usual ask. The new-situation option means the heading is a different circumstance of that slot. A confident new situation still opens a check so the user can accept or edit the heading. Jev does not invent situation names. One request per field was rejected because the free BeatAPI tier allows one successful call per minute, so a ten-field form would not finish on one click. Sending the answers was rejected because the call is deciding which slot a wording means, and the answer is not required for that decision.
